# Hassaan's Portfolio

A modern, responsive personal portfolio built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** [https://mhassaan3.github.io/Portfolio/](https://mhassaan3.github.io/Portfolio/)

---

## Preview

![Portfolio Preview](./Asset/mhassaan3.github.io-portfolio.png)

---

## Features

- Responsive design (desktop, tablet, mobile)
- Dark theme with orange accent
- Hero section with animated profile
- Services showcase with icons
- Project grid with tech stack tags
- About section with skills
- Client testimonials
- Contact form
- Smooth scroll animations
